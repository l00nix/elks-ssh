# Persistent-state SSH experiment — 2026-11-05

The separate `dropbear-persistent` server passes **11 OpenSSH session cases in
QEMU using freshly provisioned persistent state**, without a serial or LAN
entropy helper. A PPC-shaped image also starts networking and SSH automatically
and runs `ps` and `cat /etc/issue` over a pinned-key connection in QEMU.
The fresh physical test image is prepared but **PPC SSH validation is pending**.
This is not a production release or a storage/security qualification claim.

## Physical recovery and non-disclosing checker

The PPC recovery power cycle passed: generation one survived, the next request
returned the second public vector rather than repeating the first, and the
complete generation-two state matched the reference. The [recovery record](PROVISIONING.md)
contains the physical evidence.

The new `rngcheck` consumes and wipes one 32-byte request and prints only success
or refusal. Unlike the public vector probe, it never prints generated bytes or
stage diagnostics. Its six QEMU cases cover normal consumption, invalid
arguments, missing state, a busy lock, damaged checksum, and continuation after
reboot with temporary host-provisioned secret state. All pass. The PPC then
consumed the third public recovery request with this checker; full state matched
generation three, output stayed undisclosed, and the lock was absent afterwards.
No private seed or SSH keys have been transferred over Telnet/FTP.

The checker has 9,872 bytes of linked code and reserves 12,960 bytes of near
memory before arguments/environment, including an 8,192-byte stack. Its linked
8086 instruction audit passes. The adapter's compiler-reported frame is 2,338
bytes plus callees; this is not a complete SSH stack bound.

Evidence: [checker audit](evidence/20261105-rngcheck/rngcheck-audit.json),
[six QEMU cases](evidence/20261105-rngcheck/qemu-result.json), and
[physical checker result](evidence/20261105-rngcheck/ppc/result.json).

## Dropbear integration

The experimental Makefile has a separate object directory and output name. It
keeps Dropbear's protocol, authentication, algorithms and internal PRNG intact.
A small source wrapper accepts Dropbear's initial nonblocking-source flag and
its zero-flags retry; the persistent consumer itself remains unchanged. There
is no entropy collection wait, but disk I/O can block. Lock contention or an
uncertain operation refuses the affected process's requests.

Two conditional changes in `dbrandom.c` apply only to this variant: source failure
terminates instead of falling back to `/dev/urandom`, and optional random-device
writeback is disabled. The normal and assisted builds retain their own policies.
No kernel, libc, architecture or PicoMEM firmware changes are required.

The linked server SHA-256 is
`f4f1c03f0c0cc824dc1d5f088e11240d1e176506dd0d5bb00fb56c63cd21bfee`.
Its 53,888-byte first code segment and 33,616-byte second segment pass the static
8086 audit. Near-memory reservation is 42,752 bytes before arguments/environment,
including 16 KiB heap and 8 KiB stack. Whole-session samples report a 130,416-byte
process size, maximum observed heap break 13,154 bytes and minimum observed
SP-minus-break gap 6,776 bytes across 184 samples. These are observations, not
peak bounds or original-8088 performance measurements.

## Private PPC test image

The private candidate builder accepts only the known preserved `ssh2.img` and
the audited server/checker binaries. It makes a new image, provisions fresh state
and independent host/client keys, removes the byte-printing probe, and checks
private target ownership/modes. It preserves the kernel and hardware boot
options. A user-space startup command launches SSH on port **2222**; Telnet/FTP
autostart is disabled in this new image. This prevents those plaintext services
from exposing the new secrets and reduces competing memory use.

The hardware `sshtrial.img` has never been booted by QEMU. An unmounted
read-only filesystem check passes and leaves its bytes unchanged. The private
image and client key remain outside the repository; only the image is to be
copied to PicoMEM. The Mac retains a pre-pinned host key and dedicated client
key. Once physical boot is confirmed, retire the Mac's initial image copy so it
cannot restore old generator state. Never clone this image to another device.
The original public `ssh2.img` and `sshrec.img` remain available unchanged.

The owner has been asked to transfer and boot this distinct image. The running
public PPC fixture was only given the non-disclosing checker; no private state
was installed or SSH listener started through its Telnet/FTP connection.

## Remaining release gates

Physical SSH execution, memory/performance and Mac/Windows captures remain to
be tested. The inherited target crypto arithmetic has unresolved timing-security
questions; this integration does not resolve them. The storage model still
assumes qualified durable writes: readback and finite delayed power cuts do not
prove all cache/power-loss behavior. Arbitrary restored/cloned valid state cannot
be detected locally and requires fresh provisioning. A general installer,
recovery tooling, broader failure/concurrency qualification, interactive controls,
SFTP and a release review remain open. No invitation to ghaerr has been sent.

## Reproduce

```sh
ELKSSH_ELKS=/path/to/prepared/elks sh feasibility/toolchain/build-rngcheck.sh
ELKSSH_ELKS=/path/to/prepared/elks sh experimental/persistent-entropy/build-server.sh
sh experimental/persistent-entropy/build-host-seed.sh feasibility/build/host-seed
python3 tests/qemu_ssh.py --image /path/to/hd32-minix14.img \
  --filesystem minix --mfs feasibility/build/mfs \
  --server feasibility/build/persistent-server/dropbear-persistent \
  --persistent-entropy --seed-helper feasibility/build/host-seed/seed-record \
  --cpu 486 --suite --session-suite --out feasibility/test-output/persistent-ssh
```

For refusal tests omit suites and add `--persistent-fault missing`, `busy` or
`checksum`. The explicit build-output override `ELKSSH_PERSIST_SERVER_OUT` can
place large build artifacts on a separate filesystem without changing ELKS.
